🔐 RC4 Cipher

Watch the algorithm shuffle and generate an unbreakable keystream

1. Key Scheduling Algorithm (KSA)

KSA: Takes your key and shuffles a table of numbers 0–255. Each shuffle step swaps two positions based on the key bytes. The final shuffled table (S-box) is the secret state used to generate the keystream.

S-box state: Green cells = initialized. Orange = i (read position) Cyan = j (swap target)

2. Pseudo-Random Generation Algorithm (PRGA)

PRGA: After KSA finishes, generate keystream bytes one at a time. Each byte is derived from the S-box by advancing i and j, then extracting a value. These keystream bytes are random-looking (but deterministic from the key) — they're what gets XORed with your plaintext.
Keystream bytes will appear here (hex and decimal)...
Example: keystream = [0xd4, 0x7a, 0x3e, ...] = [212, 122, 62, ...]

3. XOR Encryption / Decryption

The Magic: XOR each plaintext byte with each keystream byte → ciphertext. Same XOR with the keystream again → plaintext back. The ciphertext is unbreakable because only someone with your key can generate the same keystream.
