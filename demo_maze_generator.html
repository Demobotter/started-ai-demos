Generate perfect mazes with recursive backtracking algorithm

15×15
How it works

This generator uses the Recursive Backtracking Algorithm, a depth-first search that carves paths through a grid. Starting from a random cell, the algorithm randomly chooses an unvisited neighbor, carves a passage, and repeats. When stuck, it backtracks until finding an unvisited cell. The result is a perfect maze — one with exactly one path between any two cells.
