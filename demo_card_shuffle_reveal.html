How it works: A riffle shuffle is a permutation—a rearrangement. The deck follows a mathematical pattern. If you shuffle the same way enough times, it returns to the start.
In-Shuffle: The top card stays on top. Cycle length: 8 shuffles.
Out-Shuffle: The top card moves to position 2. Cycle length: 52 shuffles.
Disorder: Sum of squared distances from original position. Resets to 0 when the cycle completes.
